# YORIMICHI 公式HP 社員更新システム 仕様書（場所プルダウン方式）

作成: 2026-07-27 / 担当: システム・IT部 / 方式: 太田確定（A案・場所プルダウン）

## 1. 目的
社員がGoogleスプレッドシートだけで、公式HPの**全ページ・全情報**を更新できるようにする。
Claude Code / git を触らずに「ページ→場所」をプルダウンで選び、内容を書けば自動反映される。

## 2. 対象ユーザー / 前提
- 更新者: YORIMICHIスタッフ（非エンジニア）。Googleシートは日常利用済み。
- 反映先: GitHub Pages（`pokerroomyorimichi/yorimichi-web`）。費用¥0。

## 3. 全体アーキテクチャ
```
[社員] Googleシート入力（ページ/場所=プルダウン, 操作, 内容）
   │  ※シートは「ウェブに公開(CSV)」で読み取り公開
   ▼
[GitHub Actions] 5分毎(cron)＋手動＋「今すぐ反映」ボタン
   │  1) 公開CSVを取得
   │  2) overlay_build.py が data-slot に内容を上書き / 追加 / 削除
   │  3) 変更があれば commit → push
   ▼
[GitHub Pages] 数分で本番反映
```

## 4. 「場所」の指定方式（確定）
- 全ページの編集可能要素に一意の `data-slot="<pageKey>-<番号>"` を**一度だけ**付与（baked-in・以後不変）。
- 各slotに日本語ラベル（例: 「参加費 - 金額」）を対応させた**登録簿(registry)**を生成。
- シートの「ページ」「場所」列はこの登録簿からのプルダウン。→ 選び間違い・タイプミスなし。

## 5. データ構造

### 5-1. 登録簿 `data/slots.json`（自動生成・システム用）
```json
{ "pageKey":"for_beginner", "pageLabel":"初めての方",
  "slotId":"for_beginner-007", "group":"参加費", "role":"金額",
  "type":"text", "current":"¥3,000" }
```

### 5-2. 入力シート「HP更新」タブ（社員が触る）
| 列 | 内容 | 例 |
|---|---|---|
| ページ | プルダウン | 初めての方 |
| 場所 | プルダウン（そのページのslot） | 参加費 - 金額(¥3,000) |
| 操作 | 修正 / 削除 | 修正 |
| 内容 | 新しいテキスト or 画像URL | ¥3,500 |
| 更新者 | 記入任意 | ルナ |
| 反映状態 | 自動記入（済/エラー） | ✅ 済 |

### 5-3. 追加コンテンツ用タブ（NEWS等・Phase2）
「NEWS」「トーナメントイベント」等はテンプレ行を1行足すと新規カードが増える。

## 6. 主要ロジック（overlay_build.py）
1. 公開CSVを取得しパース。
2. 各 `修正` 行: 対象ページHTMLの `[data-slot=slotId]` の内容（text型=innerText / image型=src）を置換。
3. 各 `削除` 行: 要素を非表示（`hidden`付与）。
4. 変更後HTMLを保存 → git差分があればcommit。
5. 冪等（同じシートで再実行しても副作用なし）。

## 7. 編集対象に含める / 含めない
- 含める: page-hero(見出し/リード/英字), 各blockの見出し・本文, 料金, カード, ステップ, 記事本文, 表, コンテンツ画像。
- 含めない: 共通ヘッダー/ドロワー/フッター/フロートCTA/パンくず（誤爆防止）。※これらの共通文言は別途「共通」ページとして限定的に開放可。

## 8. 完成の判定基準（受け入れ条件）
- [ ] 全ページの主要情報がシートから修正できる
- [ ] ページ/場所がプルダウンで選べる（登録簿連動）
- [ ] シート入力→5分以内に本番反映
- [ ] 「今すぐ反映」で即時反映も可能
- [ ] 誤入力でレイアウトが崩れない（text/imageのみ差し替え）
- [ ] 既存のライブ連携（ランキング/稼働状況）を壊さない

## 9. トリガー / 認証
- 反映: GitHub Actions（cron 5分 + workflow_dispatch + repository_dispatch）。
- push: Actions標準の GITHUB_TOKEN（追加シークレット不要）。
- シート読取: 「ウェブに公開」CSV（公開情報のため機密なし・シークレット不要）。

## 10. フェーズ
- Phase1: 修正エンジン（全ページの既存情報を修正・本仕様の中核）
- Phase2: 追加エンジン（NEWS/トーナメント/イベントの新規追加）
- Phase3: 「今すぐ反映」ボタン（GAS）・反映状態のシート書き戻し
